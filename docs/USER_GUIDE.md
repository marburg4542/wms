## 1. ภาพรวมระบบ

WMS ใช้จัดการสต็อกอะไหล่/สินค้าในคลัง รองรับ:
- **รับเข้า (Inbound)** — บันทึกอะไหล่ที่รับเข้าคลัง
- **เบิกออก (Outbound)** — พนักงานขอเบิก → ผู้ดูแลอนุมัติ → ส่งมอบ
- **ติดตามสต็อกแบบเรียลไทม์** — ยอดอัปเดตทันทีเมื่อมีการเคลื่อนไหว
- **รายงาน PDF** — ประวัติการทำรายการย้อนหลังรายวัน/เดือน/ปี
- **สแกนบาร์โค้ด/QR** — ค้นหาสินค้าด้วยกล้องมือถือหรือเครื่องสแกน

เปิดใช้งานผ่านเว็บเบราว์เซอร์ทั้งบนคอมพิวเตอร์และมือถือ (ติดตั้งเป็นแอปได้)

## 2. บทบาทและสิทธิ์การใช้งาน

| ความสามารถ | Viewer | Operator | Manager | Admin |
|---|:---:|:---:|:---:|:---:|
| ดูแดชบอร์ด / สินค้าคงคลัง | ✅ | ✅ | ✅ | ✅ |
| ออกรายงาน PDF | ✅ | ✅ | ✅ | ✅ |
| ขอเบิกสินค้า (ใบเบิก) | ❌ | ✅ | ✅ | ✅ |
| จัดการสินค้า (เพิ่ม/แก้ไข/รับเข้า) | ❌ | ❌ | ✅ | ✅ |
| ปิดใช้งาน/คืนสถานะ/ลบสินค้า | ❌ | ❌ | ✅ | ✅ |
| อนุมัติ/ปฏิเสธ/ส่งมอบใบเบิก | ❌ | ❌ | ✅ | ✅ |
| นำเข้า/ส่งออก CSV | ❌ | ❌ | ✅ | ✅ |
| จัดการผู้ใช้งาน (อนุมัติ/สิทธิ์/ลบ) | ❌ | ❌ | ❌ | ✅ |

> **สรุป:** Viewer = ดูอย่างเดียว · Operator = เบิกของได้ · Manager = จัดการคลังได้เต็มที่ · Admin = จัดการคนได้ด้วย

## 3. เริ่มต้นใช้งาน (ทุกคน)

### สมัครสมาชิก
1. เปิดเว็บ → คลิก **"สมัครสมาชิก"**
2. กรอกชื่อผู้ใช้ อีเมล และรหัสผ่าน (อย่างน้อย 8 ตัวอักษร)
3. รอ **ผู้ดูแลระบบอนุมัติ** — จะได้รับอีเมลแจ้งเมื่ออนุมัติแล้ว
4. ผู้สมัครใหม่จะได้สิทธิ์ **Viewer** เริ่มต้น (Admin ปรับสิทธิ์ให้ภายหลัง)

### เข้าสู่ระบบ
- กรอกชื่อผู้ใช้ + รหัสผ่าน
- ติ๊ก **"จดจำชื่อผู้ใช้"** เพื่อไม่ต้องพิมพ์ชื่อซ้ำครั้งหน้า
- **หมายเหตุ:** 1 บัญชีใช้ได้ทีละ 1 อุปกรณ์ — ถ้า login เครื่องใหม่ เครื่องเก่าจะถูกตัดออกอัตโนมัติ และเมื่อปิดแท็บ/เบราว์เซอร์ต้อง login ใหม่ทุกครั้ง

### ลืมรหัสผ่าน
1. หน้า login → คลิก **"ลืมรหัสผ่าน?"**
2. กรอกอีเมลที่ใช้สมัคร → ระบบส่งลิงก์รีเซ็ตไปที่อีเมล
3. คลิกลิงก์ในอีเมล (มีอายุ 30 นาที) → ตั้งรหัสผ่านใหม่

## 4. คู่มือตามบทบาท

### 👁️ Viewer (ผู้ชม — ดูอย่างเดียว)

**เข้าถึงได้:** แดชบอร์ด, สินค้าคงคลัง

- **ดูภาพรวม** ที่แดชบอร์ด: จำนวนสินค้า, สต็อกต่ำ, รับเข้า/เบิกออกวันนี้, ประวัติการทำรายการ
- **ดูสินค้าคงคลัง**: ค้นหา, กรองตามหมวดหมู่, ดูยอดคงเหลือและสถานะ
- **ออกรายงาน PDF**: กดปุ่ม "นำออก PDF" ที่แดชบอร์ด เลือกช่วงเวลา
- ❌ ไม่สามารถกดเบิกสินค้าได้ (ไม่มีปุ่มเบิก)

---

### 📦 Operator (พนักงาน — เบิกของได้)

**เข้าถึงได้:** ทุกอย่างของ Viewer + ขอเบิกสินค้า

**วิธีขอเบิกสินค้า:**
1. ไปหน้า **สินค้าคงคลัง**
2. ค้นหาสินค้า (พิมพ์ หรือกดปุ่ม 📷 สแกนบาร์โค้ด)
3. กด **"เพิ่มลงใบเบิก"** ที่สินค้าที่ต้องการ (เพิ่มได้หลายรายการ)
4. กดปุ่ม **"🛒 ตะกร้าใบเบิก"** มุมล่างขวา
5. ปรับจำนวนแต่ละรายการ (ปุ่ม − / + หรือพิมพ์)
6. กรอก **ชื่อโปรเจกต์/เหตุผลการเบิก**
7. กด **"ส่งใบเบิก"**

**ติดตามผล:**
- ดูสถานะที่แดชบอร์ด และรับ **แจ้งเตือน** เมื่อผู้ดูแลพิจารณา (มีเสียง + ข้อความ)
- เมื่ออนุมัติแล้วขึ้น **"มารับสินค้าได้"** → ไปรับของที่คลัง
- ยกเลิกใบเบิกที่ยังรออนุมัติได้

---

### 🏷️ Manager (ผู้จัดการ — จัดการคลังเต็มที่)

**เข้าถึงได้:** ทุกอย่างของ Operator + จัดการสินค้า + อนุมัติใบเบิก
*(สิทธิ์เทียบเท่า Admin ทุกอย่าง ยกเว้นจัดการผู้ใช้งาน)*

**จัดการสินค้า (หน้า "รายการอะไหล่"):**
- **เพิ่มสินค้าใหม่**: เลือกหมวดหมู่ → SKU สร้างอัตโนมัติ (เว้นว่าง) หรือกรอกเลขท้ายเอง → ใส่ชื่อ/หน่วย/ผู้ขาย/สต็อกขั้นต่ำ/รูป
- **แก้ไขสินค้า**: กด "แก้ไข" ที่การ์ด (แก้ SKU ได้ ต้องขึ้นต้นด้วยรหัสหมวด)
- **รับอะไหล่เข้า**: กด "รับเข้า" ที่การ์ด → กรอกจำนวน
- **ปิดใช้งาน/คืนสถานะ/ลบถาวร**: เปิด toggle "ที่ปิดใช้งาน" เพื่อดูและจัดการสินค้าที่ปิดไว้
- **นำเข้า/ส่งออก CSV**: อัปเดตสินค้าทีละมาก

**พิจารณาใบเบิก (หน้าแดชบอร์ด):**
1. ในตาราง "คำขอเบิกรอดำเนินการ" กด **"ตรวจสอบ"**
2. ปรับจำนวนอนุมัติแต่ละรายการ (อนุมัติเต็ม/บางส่วน/ไม่อนุมัติ)
3. **กรอกเหตุผล** (จำเป็นเมื่อปฏิเสธ หรืออนุมัติไม่ครบ)
4. กด "บันทึกการอนุมัติ" หรือ "ปฏิเสธทั้งใบ"
5. เมื่อพนักงานมารับของ → กด **"ส่งมอบแล้ว ✓"** เพื่อปิดใบเบิก

**สต็อกต่ำ:** กดการ์ด "สต็อกต่ำ" ที่แดชบอร์ด → ไปหน้าสินค้าที่กรองเฉพาะสต็อกต่ำ

---

### 👥 Admin (ผู้ดูแลระบบ — จัดการคนได้ด้วย)

**เข้าถึงได้:** ทุกอย่างของ Manager + จัดการผู้ใช้งาน

**จัดการผู้ใช้งาน (หน้า "จัดการผู้ใช้งาน"):**
- **อนุมัติคำขอสมัคร**: ผู้สมัครใหม่ขึ้นสถานะ "รออนุมัติ" → กด **"อนุมัติ"** หรือ "ปฏิเสธ" (ระบบส่งอีเมลแจ้ง)
- **กำหนดบทบาท**: เปลี่ยน role ผ่าน dropdown (Admin/Manager/Operator/Viewer)
- **ระงับ/คืนสิทธิ์**: ระงับบัญชีที่ไม่ให้ใช้ หรือคืนสิทธิ์บัญชีที่ถูกระงับ
- **ลบผู้ใช้**: ลบถาวรออกจากระบบ
- **กรองตามสถานะ**: ดูเฉพาะ Active / Pending / Denied

> ⚠️ ระบบป้องกันไม่ให้ลด/ลบ **Admin คนสุดท้าย** และลบบัญชีตัวเองไม่ได้

## 5. ฟีเจอร์ทั่วไป

### 🔔 การแจ้งเตือน (กระดิ่ง)
- อัปเดตแบบเรียลไทม์ + มีเสียงเมื่อมีรายการใหม่
- **Admin/Manager**: แจ้งเมื่อมีคำขอเบิกใหม่ / คำขอสมัครสมาชิก
- **Operator**: แจ้งผลใบเบิกของตัวเอง
- คลิกที่ข้อความ → พาไปหน้าที่เกี่ยวข้อง · กด "อ่านทั้งหมด" / "ล้างทั้งหมด" ได้

### 📷 สแกนบาร์โค้ด/QR
- **มือถือ/แท็บเล็ต**: กดปุ่ม 📷 → เปิดกล้องสแกน
- **คอมพิวเตอร์**: กดปุ่ม 📷 → ใช้เครื่องสแกนบาร์โค้ด USB ยิงลงช่องค้นหา
- รหัสที่สแกนได้จะเข้าช่องค้นหาอัตโนมัติ

### 🌗 โหมดสว่าง/มืด
กดปุ่มรูปพระอาทิตย์/พระจันทร์บนแถบด้านบน (จำค่าไว้ให้)

### ⚙️ ตั้งค่าบัญชี
เมนูโปรไฟล์ (มุมขวาบน) → "ตั้งค่าบัญชี": เปลี่ยนชื่อผู้ใช้, อีเมล, รหัสผ่าน, รูปโปรไฟล์

### 📱 ติดตั้งเป็นแอป (PWA)
เมื่อเปิดผ่าน https จะมีแบนเนอร์ "ติดตั้ง WMS เป็นแอป" — กดเพื่อเพิ่มไอคอนบนหน้าจอโฮม เปิดใช้เหมือนแอปจริง

## 6. คำถามที่พบบ่อย

**Q: login แล้วถูกเด้งออก "บัญชีนี้ถูกเข้าสู่ระบบจากอุปกรณ์อื่น"**
A: 1 บัญชีใช้ได้ทีละ 1 อุปกรณ์ — มีคนเอาบัญชีเดียวกันไป login ที่อื่น แต่ละคนควรมีบัญชีของตัวเอง

**Q: สมัครแล้ว login ไม่ได้**
A: บัญชีต้องรอ Admin อนุมัติก่อน (สถานะ "รออนุมัติ")

**Q: ลิงก์รีเซ็ตรหัสผ่านใช้ไม่ได้**
A: ลิงก์มีอายุ 30 นาที และใช้ได้ครั้งเดียว — ขอใหม่ถ้าหมดอายุ

**Q: เบิกของแล้วสต็อกยังไม่ลด**
A: สต็อกจะลดเมื่อ **ผู้ดูแลอนุมัติ** ไม่ใช่ตอนส่งใบเบิก

**Q: หาสินค้าไม่เจอในหน้าเบิก**
A: สินค้าที่ถูก "ปิดใช้งาน" จะไม่แสดง — ให้ Manager/Admin คืนสถานะก่อน

**Q: สแกนกล้องไม่ทำงาน**
A: กล้องใช้ได้เฉพาะเมื่อเปิดผ่าน https (โดเมนจริง) เท่านั้น ไม่ทำงานบน http
