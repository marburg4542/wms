# คู่มือดูแลเครื่องที่รัน WMS

โฟลเดอร์นี้คือ **แผงควบคุมของเครื่องที่รันระบบคลังให้บริษัทใช้** ไม่ใช่เครื่องที่ใช้เขียนโค้ด

ทุกอย่างในนี้เป็นไฟล์ที่กดใช้ได้เลย ไม่ต้องพิมพ์คำสั่งเอง และไม่ต้องเขียนโปรแกรมเป็นก็ใช้ได้

---

## ผู้ดูแลระบบคนใหม่ อ่านแค่ 3 ข้อนี้ก่อน

**1. ระบบดูแลตัวเองได้เกือบหมดแล้ว** — เปิดเครื่องแล้วระบบขึ้นเอง ถ้าระบบล่มจะเปิดใหม่ให้เอง และสำรองข้อมูลทุกวันเอง ไม่ต้องทำอะไรในภาวะปกติ

**2. เวลามีคนบอกว่าเข้าเว็บไม่ได้ ให้กด `check-wms.bat` เป็นอย่างแรกเสมอ** — มันจะบอกเองว่าเสียตรงไหนและต้องกดไฟล์ไหนแก้

**3. ห้ามแก้ไฟล์ใดๆ บนเครื่องนี้** — ถ้าจะแก้ระบบ ต้องแก้ที่เครื่องพัฒนาแล้วส่งขึ้น GitHub จากนั้นมากด `update-wms.bat` ที่เครื่องนี้

---

## เครื่องนี้มีสองส่วนที่ต้องทำงานพร้อมกัน

ถ้าไม่รู้ข้อนี้ จะสับสนตอนเว็บเข้าไม่ได้ทั้งที่ดูเหมือนทุกอย่างปกติ

| ส่วน | ทำหน้าที่ | ใครดูแล |
|---|---|---|
| **ตัวระบบคลัง** | เก็บข้อมูลและแสดงหน้าเว็บ ทำงานอยู่ในเครื่อง | ไฟล์ในโฟลเดอร์นี้ |
| **ท่อเชื่อมออกอินเทอร์เน็ต** | ทำให้พนักงานเปิดเว็บจากที่ไหนก็ได้ | **Windows ดูแลเอง** ไม่เกี่ยวกับไฟล์ในนี้ |

ถ้าเปิดเว็บจากมือถือไม่ได้ **แต่**เปิด `http://localhost:5000` ที่หน้าเครื่องได้ปกติ แปลว่าปัญหาอยู่ที่ท่อ ไม่ใช่ที่ระบบ

---

## รายการไฟล์ทั้งหมด

| ไฟล์ | คืออะไร | ใช้ตอนไหน |
|---|---|---|
| `check-wms.bat` | ตรวจสุขภาพระบบ | **มีปัญหา หรือเช็คประจำสัปดาห์** |
| `update-wms.bat` | เอาโค้ดเวอร์ชันใหม่ลงเครื่อง | หลังมีการแก้ระบบและส่งขึ้น GitHub แล้ว |
| `backup-now.bat` | สำรองข้อมูลเดี๋ยวนี้ | ก่อนทำอะไรเสี่ยง หรืออยากได้สำเนาสดๆ |
| `stop-wms.bat` | หยุดระบบชั่วคราว | ตอนต้องปิดระบบให้คนใช้ไม่ได้ชั่วคราว |
| `start-wms.bat` | เปิดระบบกลับ | หลังกดหยุด |
| `install-wms-task.bat` | ตั้งให้ Windows เปิดระบบเองตอนบูต | **ครั้งเดียว** ตอนติดตั้งเครื่องใหม่ |
| `install-backup-task.bat` | ตั้งให้ Windows สำรองข้อมูลทุกวัน | **ครั้งเดียว** ตอนติดตั้งเครื่องใหม่ |
| `run-wms.bat` | ตัวที่ Windows หยิบไปเปิดระบบ | **ห้ามกดเอง** |
| `register-backup-task.ps1` | ตัวช่วยของ `install-backup-task.bat` | **ห้ามกดเอง** |

> **ทุกไฟล์ต้องคลิกขวา → Run as administrator** ยกเว้น `check-wms.bat` ที่ใครกดก็ได้
> ถ้าเผลอดับเบิลคลิกธรรมดา มันจะเตือนแล้วปิดไปเอง

# ส่วนที่ 1 — ปุ่มที่ใช้บ่อย

## `check-wms.bat` — ตรวจสุขภาพระบบ

**กดเมื่อไหร่:** มีคนบอกว่าเข้าเว็บไม่ได้ · หรือเช็คประจำสัปดาห์ละครั้ง

**ทำอะไร:** ดูให้ 6 อย่างในหน้าเดียว — ระบบเปิดอยู่ไหม · Windows จะเปิดให้ตอนบูตไหม · ท่อต่ออยู่ไหม · สำรองข้อมูลล่าสุดเมื่อไหร่ · และท้ายบันทึกการทำงาน

**ปลอดภัย 100%** อ่านอย่างเดียว ไม่แก้ไม่ลบอะไรทั้งนั้น กดกี่ครั้งก็ได้

---

## `update-wms.bat` — เอาโค้ดใหม่ลงเครื่อง

**กดเมื่อไหร่:** หลังจากมีคนแก้ระบบที่เครื่องพัฒนาแล้วส่งขึ้น GitHub เรียบร้อย

**ทำอะไร:** หยุดระบบ → ดึงโค้ดใหม่ → ติดตั้งส่วนประกอบ**เท่าที่จำเป็น** → สร้างหน้าเว็บใหม่ → เปิดกลับ แล้วยืนยันให้ว่ากลับมาจริง

**ใช้เวลา:** ปกติประมาณครึ่งนาที · ถ้ารอบนั้นมีส่วนประกอบใหม่จะนานหลายนาทีและ**ดูเหมือนค้าง** เป็นเรื่องปกติ อย่าปิดหน้าต่าง

**หลังอัปเดตเสร็จ** บอกพนักงานให้กด `Ctrl+Shift+R` หนึ่งครั้ง ไม่งั้นบางคนจะยังเห็นหน้าเว็บเวอร์ชันเก่าที่ค้างอยู่ในเบราว์เซอร์

---

## `backup-now.bat` — สำรองข้อมูลเดี๋ยวนี้

**กดเมื่อไหร่:** ก่อนจะทำอะไรที่เสี่ยง หรืออยากได้สำเนาสดๆ ไปเก็บ

**ทำอะไร:** คัดลอกฐานข้อมูลและรูปสินค้าทั้งหมดไปเก็บที่ `G:\wms-backups` พร้อมเก็บสำเนาไฟล์ตั้งค่าไว้ที่ `G:\wms-secrets`

**ไม่ต้องหยุดระบบ** พนักงานใช้งานต่อได้ตามปกติระหว่างที่สำรอง ไม่รู้สึกอะไรเลย

**ปกติไม่ต้องกดเอง** เพราะ Windows ทำให้ทุกวันอยู่แล้ว ปุ่มนี้มีไว้กรณีอยากได้เดี๋ยวนั้น

---

## `stop-wms.bat` และ `start-wms.bat` — หยุดและเปิดกลับ

**กดเมื่อไหร่:** ตอนต้องปิดระบบชั่วคราว เช่นจะเปลี่ยนไฟล์ข้อมูล

**ระหว่างที่หยุด พนักงานทั้งบริษัทใช้งานไม่ได้** — อย่าลืมเปิดกลับ หรือ restart เครื่องก็ได้ เพราะ Windows จะเปิดให้เองอยู่แล้ว

---

# ส่วนที่ 2 — ตั้งครั้งเดียวตอนติดตั้งเครื่องใหม่

สองไฟล์นี้กดครั้งเดียวแล้วไม่ต้องแตะอีกเลย จนกว่าจะย้ายเครื่องหรือย้ายโฟลเดอร์

## `install-wms-task.bat`

บอก Windows ว่า "ทุกครั้งที่เปิดเครื่อง ช่วยเปิดระบบคลังให้ด้วย"

งานถูกตั้งในนามบัญชี **SYSTEM** ของ Windows ไม่ใช่บัญชีของคนใดคนหนึ่ง จึงทำงาน**ตั้งแต่ตอนบูตโดยไม่ต้องรอให้ใครล็อกอิน** ถ้าไปผูกกับบัญชีคน เครื่องที่รีสตาร์ตกลางดึกจะยังเข้าไม่ได้จนกว่าจะมีคนมาเปิดเครื่องตอนเช้า

ก่อนตั้งงาน จะเช็คให้ว่ามีไฟล์ตั้งค่าครบหรือยัง ถ้ายังไม่ครบจะไม่ยอมตั้งให้ เพราะระบบจะเปิดไม่ขึ้นอยู่ดี

## `install-backup-task.bat`

บอก Windows ว่า "ทุกวันตอนตี 2 ช่วยสำรองข้อมูลให้ด้วย"

**ถ้าคืนไหนเครื่องถูกปิด มันจะตามเก็บให้ตอนเปิดเครื่องครั้งถัดไป**

# ส่วนที่ 3 — ผลลัพธ์ที่ควรได้ในแต่ละคำสั่ง

## คำที่ต้องมองหา (ใช้เหมือนกันทุกไฟล์)

| เห็นคำนี้ | แปลว่า |
|---|---|
| **`[OK]`** | ผ่าน จบ ไม่ต้องทำอะไรต่อ |
| **`[!]`** | มีปัญหา — **บรรทัดถัดไปบอกว่าต้องทำอะไร** |
| `DOWN` · `NOT REGISTERED` · `not found` | ของที่ควรมี แต่ไม่มี |
| `exit code 0` | ศูนย์คือสำเร็จ เลขอื่นคือไม่สำเร็จ |

**สามารถระบุปัญหาโดยรวมพื้นฐานได้**

- บรรทัดที่ซ้ำกันเป็นชุดแบบนี้ คือหน้าตาของอาการ **"เปิดแล้วตายวน"**
- ข้อ 5 บอกว่าเรื่องนี้เริ่มมาตั้งแต่ 13 วันก่อน ไม่ใช่เพิ่งเกิดคืนนี้

```

  Staff can keep using the system while this runs.

สำรองข้อมูลเสร็จ: G:\wms-backups\2026-09-11T09-20-15 (ฐานข้อมูล 0.82 MB, เก็บย้อนหลัง 14 ชุด)

```

> บรรทัดภาษาไทยตรงกลางมาจากเครื่องมือเดิมของระบบ บนบางเครื่องอาจขึ้นเป็น**ตัวอักษรเพี้ยนๆ**  ให้ดูบรรทัด `[OK]` ล่างสุดเป็นหลัก

## `backup-now.bat` — ไดรฟ์ปลายทางหาย

```
  [!] Drive G: was not found, so nothing was backed up.
      Edit BACKUP_DEST at the top of this file, then run it again.
```

และจะจดไว้ในไฟล์ `backup.log` ที่โฟลเดอร์บนสุดของโปรเจกต์ให้ด้วย

```
[Thu 09/10/2026 14:42:59.45] FAILED - drive G: not found, backup skipped
```

**ที่ต้องจดเพราะ** รอบอัตโนมัติตอนตี 2 ไม่มีใครเห็นหน้าจอ — บรรทัดใน `backup.log` คือหลักฐานเดียวที่บอกว่าคืนนั้นไม่ได้สำรอง

**`unchanged - skipped` สองบรรทัดนั้นเป็นเรื่องดี** แปลว่าไม่มีส่วนประกอบใหม่ เลยข้ามขั้นที่กินเวลานานไปได้

ถ้ารอบไหนมีของใหม่จะขึ้นแทนว่า `changed - reinstalling, takes several minutes and looks frozen` — ปล่อยให้ระบบอัปเดทต่อ

## `update-wms.bat` — ถูกกันไว้เพราะมีคนแก้ไฟล์บนเครื่องนี้

```
  [!] This machine has locally modified files, so the update stopped.
      It must stay an exact mirror of GitHub.

 M server/index.js

  If none of that is worth keeping, run  git reset --hard  and retry.
```

บรรทัด `M server/index.js` คือชื่อไฟล์ที่ถูกแก้ · **ตอนนี้ระบบยังหยุดอยู่** ถ้าอยากให้กลับมาก่อนให้กด `start-wms.bat`

# ส่วนที่ 4 — เวลามีปัญหา

| อาการ | น่าจะเพราะ | ทำอะไร |
|---|---|---|
| เข้าเว็บไม่ได้ | ยังไม่รู้ | กด `check-wms.bat` ก่อนเสมอ แล้วดูว่าข้อไหนขึ้นคำเตือน |
| ข้อ 1 ขึ้น `DOWN` | ระบบไม่ทำงาน | ดูข้อ 6 ว่าบอกอะไร แล้วกด `start-wms.bat` |
| ข้อ 3 บอกว่าไม่เจอบริการ | ท่อไม่ได้ต่อ | ไม่ใช่ปัญหาของไฟล์ในโฟลเดอร์นี้ ต้องตั้งท่อใหม่ |
| ข้อ 6 มีบรรทัด `restarting in 15s` ซ้ำถี่ๆ | ระบบเปิดแล้วตายวน | อ่านบรรทัดเหนือมัน มักเป็นเรื่องไฟล์ตั้งค่า |
| เปิดเว็บได้แต่หน้าเป็นเวอร์ชันเก่า | เบราว์เซอร์เก็บของเดิมไว้ | กด `Ctrl+Shift+R` |
| เข้าระบบได้แต่ไม่มีสินค้าเลย | ระบบไปเปิดฐานข้อมูลเปล่า | เปิด `server\.env` ดูบรรทัด `DB_FILE` ว่าตรงกับชื่อไฟล์ฐานข้อมูลจริงไหม |
| สำรองล่าสุดค้างมาหลายวัน | ไดรฟ์ปลายทางหาย | เปิดไฟล์ `backup.log` ดูว่าจดอะไรไว้ |

# ส่วนที่ 5 — กฎที่ห้ามพัง

## เครื่องนี้เป็นสำเนาของ GitHub เท่านั้น ห้ามแก้ไฟล์ที่นี่

ถ้ามีใครแก้ไฟล์ไว้ `update-wms.bat` จะหยุดแล้วเตือน ไม่เดินต่อ — **จงใจให้เป็นแบบนั้น**

เพราะถ้าปล่อยผ่าน การดึงโค้ดจะชนกันเงียบๆ แล้วหน้าจอจะบอกว่าอัปเดตเสร็จ ทั้งที่ระบบยังรันโค้ดเก่าอยู่ อาการแบบนี้หาสาเหตุยากมาก

## ข้อมูลไหลทางเดียวเท่านั้น

```
โค้ด    :  เครื่องพัฒนา  →  GitHub  →  เครื่องนี้
ข้อมูล  :  เครื่องนี้  →  ไฟล์สำรอง
```

**ถ้าเอาไฟล์ฐานข้อมูลจากเครื่องพัฒนามาทับเครื่องนี้** จะใช้ไฟล์ที่นำมาทับนั้นแทน และไฟล์เก่าจะถูกไฟล์ใหม่แทนไป

# ส่วนที่ 6 — ค่าที่แก้ได้

ทุกค่าอยู่บรรทัดบนสุดของไฟล์ เปิดด้วย Notepad แก้ได้เลย

| ค่า | อยู่ในไฟล์ | ตอนนี้เป็น | แก้เมื่อไหร่ |
|---|---|---|---|
| `BACKUP_DEST` | `backup-now.bat` · `check-wms.bat` | `G:\wms-backups` | เปลี่ยนไดรฟ์เก็บสำรอง |
| `SECRETS_DEST` | `backup-now.bat` | `G:\wms-secrets` | เปลี่ยนที่เก็บสำเนาไฟล์ตั้งค่า |
| `KEEP` | `backup-now.bat` | `14` ชุด | อยากเก็บย้อนหลังมากหรือน้อยลง |
| `APP_PORT` | อีก 5 ไฟล์ ที่ไม่ใช่ `backup-now` · `run-wms` | `5000` | เปลี่ยนพอร์ตของระบบ |
| `ATTIME` | `install-backup-task.bat` | `02:00` | เปลี่ยนเวลาสำรองรายวัน |

> ถ้าแก้ `BACKUP_DEST` ต้องแก้ให้ตรงกันทั้ง `backup-now.bat` และ `check-wms.bat`
> ถ้าแก้ `APP_PORT` ต้องแก้ `PORT` ใน `server\.env` ให้ตรงกันด้วย
> ถ้าแก้ `ATTIME` ต้องรัน `install-backup-task.bat` ใหม่หนึ่งครั้ง

**หนึ่งชุดสำรองกินพื้นที่ประมาณ 230 MB** ดังนั้น 14 ชุด ≈ 3.2 GB เผื่อพื้นที่ในไดรฟ์ปลายทางให้พอ

# หมายเหตุทางเทคนิค

**ทำไมข้อความในไฟล์ `.bat` เป็นภาษาอังกฤษ** — cmd.exe อ่านไฟล์ `.bat` ทีละไบต์ พอมีอักษรไทยตำแหน่งไบต์จะเลื่อน แล้วแปลคำสั่งผิดจนสคริปต์พัง โดยเฉพาะส่วนที่มีวงเล็บกับ `goto` (ทดสอบแล้วพังจริง) คำอธิบายภาษาไทยจึงมาอยู่ในไฟล์นี้แทน

**ทำไมมีไฟล์ `.ps1` ปนมาหนึ่งไฟล์** — งานสำรองข้อมูลต้องตั้งตัวเลือก "ถ้าพลาดรอบให้รันทันทีที่เปิดเครื่อง" ซึ่งคำสั่งตั้งงานแบบธรรมดาสั่งไม่ได้ ต้องใช้ PowerShell เท่านั้น

**ทำไม `run-wms.bat` วนเปิดใหม่ทุก 15 วินาที ไม่ใช่ทันที** — กันไม่ให้ไฟล์บันทึกบวมเป็น GB ภายในไม่กี่นาทีตอนที่ระบบเปิดไม่ขึ้น และไฟล์บันทึกจะถูกตัดเองเมื่อโตเกิน 10 MB โดยเก็บของเก่าไว้หนึ่งรุ่นเป็น `wms.log.old`
